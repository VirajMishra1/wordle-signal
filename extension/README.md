# Wordle Signal Chrome Extension

This is the unpacked Chrome extension version. It reads the current Wordle or Sedecordle page and recommends a guess without manual color entry.

## Load It Locally

1. Open `chrome://extensions`.
2. Enable **Developer mode**.
3. Click **Load unpacked**.
4. Select this `extension` folder.
5. Open Wordle or Sedecordle and click the extension icon.

The solver runs fully inside Chrome using bundled word lists. No Python server is required.
